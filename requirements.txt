# ComfyUI custom node requirements for HunyuanImage-3.0.
#
# torch/torchvision/torchaudio are intentionally NOT listed here - they must
# be installed first from the CUDA-specific wheel index, matching Tencent's
# official requirements.txt:
#   pip install torch==2.8.0 torchvision==0.23.0 torchaudio==2.8.0 \
#     --index-url https://download.pytorch.org/whl/cu128
# (install_dev_env.sh does this automatically). Installing torch from this
# file via the default PyPI index risks a wheel built against the wrong CUDA
# version, so don't add it back here.
#
# Versions below are floors; install_dev_env.sh applies constraints.txt
# (pinned to Tencent's tested versions, see that file) on top so pip doesn't
# silently drift to an untested newer release - unconstrained floors like
# these are what let the toolchain drift out from under instruct generation
# before, hence the reset to Eric's last commit on `dev`.
